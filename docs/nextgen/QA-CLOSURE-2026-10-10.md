## Network semantics (actual behaviour)

| Network | What it is | API |
|---|---|---|
| `bridge` | Compatibility mode: the shared Android device network, not a Linux bridge, no address range | labels `io.thothdock.network.kind=device-bridge`; connect/disconnect 403 |
| `host` | The shared Android device network | `device-host`; connect/disconnect 403 |
| `none` | Not implemented: `--network none` and connect are refused (501), never a silent fallback | `supported=false` |
| user-defined | Own 127.77.x.y address per container, names and aliases through `/etc/hosts`, outbound DNS/HTTPS | `user-defined`, range 127.77.0.0/16 |

Functional address separation, **not** enforced isolation: a container that
knows another container's address reaches it from any network (measured on
the phone; `SECURITY_MODEL.md` J).
