# ThothDock visual identity

ThothDock is the **container engine and product layer**, not a Linux
distribution. Its identity says "engine": dark graphite, silver metal, electric
cyan and blue, a Thoth-bird T standing over stacked containers. The guest inside
still identifies itself truthfully (for example *Debian GNU/Linux 13 (trixie)*).

Original artwork only. No Docker logo, whale, or trade dress.

### Terminal

| Role | Colour |
|---|---|
| Background | `#090D12` |
| Default text | `#DCE8EE` (cyan is an accent, never the default text colour) |
| Cursor | `#18E7FF` |
| Prompt user and host | `#43E6F5` |
| Prompt path | `#70AFFF` |
| Banner title / labels | `#6CF4FF` / `#80939F` |

Prompt and banner colours reach the guest as the nearest xterm-256 colour.
Programs' own ANSI colours are never remapped, and the Docker CLI's output is
never recoloured: the unmodified CLI is the compatibility proof. Errors use
`#FF6B7A`, success `#54E6A4` when ThothDock itself draws them.

## Launcher icon

- The full approved tile is the adaptive foreground, scaled so that the symbol's
  furthest solid point (the T bar's corners, 580 px from the centre of the
  1254 px source) lies on the 33 dp circle of the 66 dp safe zone. No launcher
  mask crops the symbol. Circle, squircle and rounded-square masks were
  rendered and checked.
- Background layer: the icon's own margin colour `#040508`, with `#06090D`
  glow, so the foreground's feathered edge leaves no seam.
- Monochrome (themed) layer: the symbol's silhouette (brightness above 45,
  inside the tile's bevel); the tile itself drops out.
- No text in the icon. Legible at 48 dp: the T, the bird's head and the
  container stack carry the shape. If a surface must be smaller than
  32 dp, use only the T and bird; no simplified variant file is needed yet.
- Generated by `tools/garden/branding/make_thothdock_resources.py` from the
  master; output is deterministic and every pixel is a master pixel.

## Typography

Local fonts only; nothing is downloaded at runtime. Android UI uses the
system/project UI font; the terminal keeps its bundled monospaced font
(DejaVu Sans Mono), and ligatures are not enabled. Box drawing, ASCII, Arabic UI
text and Docker's tables were checked on a device.

## Spacing

Keep clear space around the mark of at least 12% of its width. Do not place it
over busy imagery. In the app it appears at the drawer header (about 56 dp),
never as a large splash over terminal content, and no splash delay is added.

## Prohibited

- Docker's whale, logo, wordmarks or colours presented as ours.
- Recolouring, stretching, outlining, adding drop shadows, or placing the mark
  on a light background.
- Calling ThothDock a Linux distribution, or implying Docker, Inc. affiliation.
- Cyan as the default terminal text colour; all-cyan screens; large glows on
  ordinary controls.
- Claiming isolation the engine does not provide (see SECURITY_MODEL.md).

## Future Containers page — design tokens and layout

Location: **Settings → … → Containers → About**. The page is a *client of the
ThothDock API*, exactly like the Docker CLI:

```
Docker CLI ─────────\
                     ├──▶ ThothDock API (unix socket)
Android Containers UI/
```

It keeps no container state of its own.

State and kind colours (already defined as tokens):

| Token | Hex | Meaning |
|---|---|---|
| `thothdock_state_running` | `#4DE39A` | running |
| `thothdock_state_stopped` | `#6F8394` | created / stopped |
| `thothdock_state_exited` | `#8A98A3` | exited |
| `thothdock_state_error` | `#E8606F` | failed (restrained red) |
| `thothdock_kind_port` | `#147DFF` | published ports |
| `thothdock_kind_image` | `#C7D3DC` | image names |

Layout:

1. **Header**: the mark, engine status (`Running` / `Offline`), `API 1.41`,
   architecture.
2. **Summary row**: Running · Stopped · Images · Storage.
3. **Container cards**: name, image, state dot and text, uptime, published ports.
   Actions: Start, Stop, Restart, Logs. Later: Exec, Delete, Volumes, Inspect.
4. Cards use `thothdock_surface` on `thothdock_background`, a 1 dp
   `thothdock_border`, no glow. Cyan marks the focused or selected element only.
